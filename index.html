EduBoost - La Grande Tombola pour l'Éducation

SuiSco Sarl / YAS TOGO - 2025 - Present

National lottery platform built on a multi-endpoint + one central distributed architecture. 15 Django write nodes handle purchases across three channels; one central node aggregates all tickets, runs draws and manages corporate accounts. Live at eduboost.tg.

Distributed Architecture 15 write nodes → 1 central. Collision-free ticket codes: SERVER_ID + PG sequence. Celery ~500 ms sync + 30 s crash-recovery.
3 Purchase Channels Web (async, request_id polling) - SMS/USSD (synchronous <50 ms, idempotent ref_id) - Mobile money MIXX & VAS (HMAC-SHA256 webhooks).
Offrir - Corporate Gifting Portal PDF generation, SMS/email OTP (stored on central via secured internal route), claim flow, dual-proxy frontend routing.
4-Phase Live Draw Bijective ticket anonymisation → OTP voting (soiree.eduboost.tg) → tireur selection (admin) → public draw (tirage.eduboost.tg).
Security HMAC-SHA256 webhooks, Redis OTP (endpoints) & PostgreSQL OTP (central), Redis rate-limit, operator IP allowlist, SimpleJWT staff auth.
